Projetos de Consultoria em Destaque

Featured Consulting Projects

  • Gestão de IAM e SSO: Entrega de SSO para todas as aplicações internas através da integração do Office365 (AzureAD/EntraID) com o AWS Identity Center. Reutilização de tokens de segurança para Kubernetes, Keycloak, Jenkins e Elasticsearch, permitindo que o acesso à nuvem seja revogado em segundos.
  • IAM & SSO Management: Delivered SSO for all internal applications by integrating Office365 (AzureAD/EntraID) with AWS Identity Center. Reused security tokens for Kubernetes, Keycloak, Jenkins, and Elasticsearch, allowing cloud access to be revoked in seconds.
  • Arquitetura Segura de Datalake: Migração de um data lake baseado em S3 para o Amazon Lake Formation para permitir o compartilhamento seguro B2B. Gerenciamento de permissões automatizado utilizando a API REST da AWS e Boto3.
  • Secure Datalake Architecture: Migrated an S3-based data lake to Amazon Lake Formation to enable secure B2B sharing. Automated permission management utilizing the AWS REST API and Boto3.
  • Implementação de DevSecOps e SAST: Impulsionou e implementou SAST em todos os pipelines de produção para DotNet e Python usando Trivy. Relatórios automatizados fazendo upload de verificações para um bucket para visualização em dashboard do Kibana.
  • DevSecOps & SAST Implementation: Pushed for and implemented SAST across all production pipelines for DotNet and Python using Trivy. Automated reports by uploading scans to a bucket for Kibana dashboard visualization.
  • Migração para AWS SSO: Migração de roles, políticas e logins para o AWS SSO usando o Azure AD como Provedor de Identidade. Desenvolvimento de uma função Lambda usando o Microsoft Graph para automatizar atribuições de usuários.
  • AWS SSO Migration: Migrated roles, policies, and logins to AWS SSO using Azure AD as the Identity Provider. Developed a Lambda function using Microsoft Graph to automate user assignments.
  • Automação de Gestão de Vulnerabilidades: Pesquisa de ferramentas de ML e Análise de Dados para automatizar alertas baseados em vulnerabilidades conhecidas de infraestrutura. Implementação de relatórios automatizados via Nessus e Splunk.
  • Vulnerability Management Automation: Researched ML and Data Analysis tools to automate alerting based on known infrastructure vulnerabilities. Implemented automated reporting via Nessus and Splunk.
